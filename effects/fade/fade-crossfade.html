Fade Crossfade

Crossfade between two real images: the is image #1 and the ::before pseudo carries image #2 via background-image. Edit both URLs to use your own images.

Hover or focus the image to see the effect.

HTML

<div class="hover-effect fade-crossfade">
  <img src="image.jpg" alt="description">
</div>

CSS

.hover-effect.fade-crossfade{
  position: relative;
}
.hover-effect.fade-crossfade::before{
  content: "";
  position: absolute;
  inset: 0;
  background-image: url("https://picsum.photos/seed/fade-crossfade-alt/800/600");
  background-size: cover;
  background-position: center;
  opacity: 0;
  transition: opacity 0.5s ease;
}
.hover-effect.fade-crossfade img{
  transition: opacity 0.5s ease;
}
.hover-effect.fade-crossfade:hover img,
.hover-effect.fade-crossfade:focus-visible img{
  opacity: 0;
}
.hover-effect.fade-crossfade:hover::before,
.hover-effect.fade-crossfade:focus-visible::before{
  opacity: 1;
}
@media (prefers-reduced-motion: reduce) {
  .hover-effect.fade-crossfade img,
  .hover-effect.fade-crossfade::before{
    transition: none;
  }
  .hover-effect.fade-crossfade:hover img,
  .hover-effect.fade-crossfade:focus-visible img{
    opacity: 0;
  }
  .hover-effect.fade-crossfade:hover::before,
  .hover-effect.fade-crossfade:focus-visible::before{
    opacity: 1;
  }
}

Set the for image #1 and the background-image URL inside ::before for image #2. Select the code and copy with Ctrl+C or ⌘C.
