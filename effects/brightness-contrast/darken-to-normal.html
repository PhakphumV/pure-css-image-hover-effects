Darken to Normal

The image starts brightened and restores normal brightness on hover/focus.

Hover or focus the image to see the effect.

HTML

CSS

.hover-effect.darken-to-normal img{
  filter: brightness(1.4);
  transition: filter 0.5s ease;
}
.hover-effect.darken-to-normal:hover img,
.hover-effect.darken-to-normal:focus-visible img{
  filter: brightness(1);
}
@media (prefers-reduced-motion: reduce) {
  .hover-effect.darken-to-normal img{
    transition: none;
  }
  .hover-effect.darken-to-normal:hover img,
  .hover-effect.darken-to-normal:focus-visible img{
    filter: brightness(1);
  }
}

The animates filter: brightness() from 1.4 to 1 (inverse of brighten). Select the code and copy with Ctrl+C or ⌘C.
