Grayscale

The image transitions from full colour to full grayscale on hover/focus.

Hover or focus the image to see the effect.

HTML

CSS

.hover-effect.grayscale img{
  filter: grayscale(0);
  transition: filter 0.5s ease;
}
.hover-effect.grayscale:hover img,
.hover-effect.grayscale:focus-visible img{
  filter: grayscale(100%);
}
@media (prefers-reduced-motion: reduce) {
  .hover-effect.grayscale img{
    transition: none;
  }
  .hover-effect.grayscale:hover img,
  .hover-effect.grayscale:focus-visible img{
    filter: grayscale(100%);
  }
}

The animates its filter: grayscale() value from 0 to 100%. Select the code and copy with Ctrl+C or ⌘C.
