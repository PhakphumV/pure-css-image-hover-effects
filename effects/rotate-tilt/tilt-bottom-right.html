Tilt Bottom-Right

Image tilts on hover/focus with the bottom-right corner as the rotation pivot, plus a small zoom to keep the viewport covered.

Hover or focus the image to see the effect.

HTML

CSS

.hover-effect.tilt-bottom-right img{
  transform-origin: bottom right;
  transition: transform 0.5s ease;
}
.hover-effect.tilt-bottom-right:hover img,
.hover-effect.tilt-bottom-right:focus-visible img{
  transform: scale(1.4) rotate(-8deg);
}
@media (prefers-reduced-motion: reduce) {
  .hover-effect.tilt-bottom-right img{
    transition: none;
  }
  .hover-effect.tilt-bottom-right:hover img,
  .hover-effect.tilt-bottom-right:focus-visible img{
    transform: scale(1.4) rotate(-8deg);
  }
}

The animates transform: scale(1.4) rotate(-8deg) with transform-origin: bottom right. The slight scale prevents blank corners. Select the code and copy with Ctrl+C or ⌘C.
