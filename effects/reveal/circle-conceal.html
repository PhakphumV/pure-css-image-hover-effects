Circle Conceal

Inverse of circle-reveal: at idle the image is visible, on hover/focus a dark circle grows from center to cover the image.

Hover or focus the image to see the effect.

HTML

CSS

.hover-effect.circle-conceal{
  position: relative;
  display: block;
}
.hover-effect.circle-conceal::before{
  content: "";
  position: absolute;
  inset: 0;
  background: rgba(15, 23, 42, 0.85);
  clip-path: circle(0% at 50% 50%);
  transition: clip-path 0.5s ease;
  pointer-events: none;
}
.hover-effect.circle-conceal:hover::before,
.hover-effect.circle-conceal:focus-visible::before{
  clip-path: circle(150% at 50% 50%);
}

The ::before grows from clip-path: circle(0%) to circle(150%) at center on hover/focus, concealing the image with a dark iris. Select the code and copy with Ctrl+C or ⌘C.
