Corner Reveal

A dark overlay covers the image at idle, then shrinks to a small triangle at the bottom-right corner on hover/focus, revealing the rest of the image.

Hover or focus the image to see the effect.

HTML

CSS

.hover-effect.corner-reveal{
  position: relative;
  display: block;
}
.hover-effect.corner-reveal::before{
  content: "";
  position: absolute;
  inset: 0;
  background: rgba(15, 23, 42, 0.85);
  clip-path: polygon(0 0, 100% 0, 100% 100%, 0 100%);
  transition: clip-path 0.5s ease;
  pointer-events: none;
}
.hover-effect.corner-reveal:hover::before,
.hover-effect.corner-reveal:focus-visible::before{
  clip-path: polygon(100% 100%, 100% 50%, 50% 100%);
}

The ::before shrinks from a full rectangle polygon to a small bottom-right triangle on hover/focus, revealing the image with a corner-tuck wipe. Select the code and copy with Ctrl+C or ⌘C.
