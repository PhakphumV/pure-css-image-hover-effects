Vertical Split

Two halves of a dark overlay cover the image at idle, then slide apart vertically on hover/focus, revealing the image as the overlay splits vertically.

Hover or focus the image to see the effect.

HTML

CSS

.hover-effect.vertical-split{
  position: relative;
  display: block;
  overflow: hidden;
}
.hover-effect.vertical-split::before,
.hover-effect.vertical-split::after{
  content: "";
  position: absolute;
  left: 0;
  right: 0;
  height: 50%;
  pointer-events: none;
  transition: transform 0.5s ease;
}
.hover-effect.vertical-split::before{
  top: 0;
  background: rgba(15, 23, 42, 0.85);
  transform: translateY(0);
}
.hover-effect.vertical-split::after{
  bottom: 0;
  background: rgba(15, 23, 42, 0.85);
  transform: translateY(0);
}
.hover-effect.vertical-split:hover::before,
.hover-effect.vertical-split:focus-visible::before{
  transform: translateY(-100%);
}
.hover-effect.vertical-split:hover::after,
.hover-effect.vertical-split:focus-visible::after{
  transform: translateY(100%);
}

Two pseudo-elements, each 50% tall, slide apart vertically on hover/focus, revealing the image as the overlay splits. Select the code and copy with Ctrl+C or ⌘C.
