Glow

A colored purple halo blooms around the image on hover/focus, creating a luminous glow.

Hover or focus the image to see the effect.

HTML

CSS

.hover-effect.glow img{
  transition: box-shadow 0.4s ease;
  box-shadow: 0 0 0 0 rgba(124, 58, 237, 0);
}
.hover-effect.glow:hover img,
.hover-effect.glow:focus-visible img{
  box-shadow:
    0 0 30px 6px rgba(124, 58, 237, 0.55),
    0 0 60px 12px rgba(124, 58, 237, 0.25);
}

The animates its box-shadow from transparent to a two-layer purple halo on hover/focus. Select the code and copy with Ctrl+C or ⌘C.
