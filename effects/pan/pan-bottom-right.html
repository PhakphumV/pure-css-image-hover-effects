Pan Bottom Right

Image slides diagonally toward the bottom-right corner, revealing more of the top-left.

Hover or focus the image to see the effect.

HTML

<div class="hover-effect pan-bottom-right">
  <img src="image.jpg" alt="description">
</div>

CSS

.hover-effect.pan-bottom-right{
  overflow: hidden;
}
.hover-effect.pan-bottom-right img{
  width: calc(100% + 30px);
  height: calc(100% + 30px);
  transition: transform 0.45s ease;
}
.hover-effect.pan-bottom-right:hover img,
.hover-effect.pan-bottom-right:focus-visible img{
  transform: translate(-30px, -30px);
}
@media (prefers-reduced-motion: reduce) {
  .hover-effect.pan-bottom-right img{
    transition: none;
  }
  .hover-effect.pan-bottom-right:hover img,
  .hover-effect.pan-bottom-right:focus-visible img{
    transform: none;
  }
}
