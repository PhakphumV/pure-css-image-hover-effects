Point Zoom

Zoom hover effect on the image.

Hover or focus the image above to see the effect.

HTML

<div class="hover-effect point-zoom">
  <img src="image.jpg" alt="description">
</div>

CSS

.hover-effect.point-zoom img{
  transform-origin: 65% 75%;
  transition: transform 0.4s ease-out;
}
.hover-effect.point-zoom:hover img, .hover-effect.point-zoom:focus-visible img{
  transform: scale(5);
}
