Zoom In

Zoom hover effect on the image.

Hover or focus the image above to see the effect.

HTML

<div class="hover-effect zoom-in">
  <img src="image.jpg" alt="description">
</div>

CSS

/* Zoom In Effect */

.hover-effect.zoom-in img{
  transition: transform 0.45s ease;
}

.hover-effect.zoom-in:hover img, .hover-effect.zoom-in:focus-visible img{
  transform: scale(1.18);
}
